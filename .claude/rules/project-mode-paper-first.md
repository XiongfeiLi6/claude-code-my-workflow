# Project Mode: Paper-First (Default)

This repository originated from a slide-centric template. For this project, default operating mode is manuscript referee workflow.

## Default Behavior

- Prioritize manuscript reading, critique, report drafting, and polished PDF output.
- Use report paths under `quality_reports/referee_reports/` and `output/pdf/`.
- Treat slide/Beamer/TikZ/Quarto lecture rules as dormant unless explicitly requested.

## Dormant-by-Default Modules

The following are retained but optional:
- Beamer/Quarto lecture sync workflows
- TikZ extraction and SVG pipelines
- lecture deployment workflows

## Activation Rule

Only activate dormant modules when the user explicitly asks for slide-related work.

## Review Standard

Top-journal referee standard with constructive tone and explicit evidence anchors.
